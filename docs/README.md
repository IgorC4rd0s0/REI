# Documentação do R.E.I.

Esta pasta concentra os documentos de apresentação, suas fontes editáveis e os materiais de referência do projeto.

## PDFs

- [Guia do Sistema R.E.I.](pdf/Guia_REI.pdf)
- [Fluxograma técnico](pdf/Fluxograma_Tecnico_REI.pdf)
- [Fluxograma operacional](pdf/Fluxograma_Guia_REI.pdf)

## Organização

- `pdf/`: documentos finais para leitura e compartilhamento;
- `sources/`: arquivos HTML usados para gerar os PDFs;
- `reference/`: materiais de apoio usados na criação dos formulários.

Os PDFs são gerados a partir das fontes HTML pelo Microsoft Edge em modo headless. Os documentos utilizam as logos oficiais mantidas em `web/assets` para evitar duplicação de arquivos.
